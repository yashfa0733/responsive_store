SHOPSPACE — LAB 4: CSS LAYOUT + RESPONSIVE E-COMMERCE FRONTEND

RUN:
1. Download and extract this ZIP.
2. Open the Responsive_Store_Lab4 folder.
3. Double-click index.html in Chrome, Edge or Firefox.
   Or open the folder in VS Code and run index.html with Live Server.
No XAMPP, PHP, database or build step is required.

PAGES:
index.html - Home
products.html - Products, category filter, search and sorting
product.html - Product details and quantity selector
cart.html - Shopping cart, quantity update, remove item, summary
checkout.html - Responsive checkout form
login.html - Demo login
register.html - Demo registration
css/style.css - Shared styling with CSS Grid, Flexbox and responsive breakpoints
js/app.js - Shopping cart, validation and interactions
images/ - Local SVG product illustrations (offline-ready)

FUNCTIONAL FEATURES:
- Add items from Products or Product Details.
- Cart is saved in browser localStorage.
- Increase/decrease quantity and remove cart items.
- Search products, filter categories and sort by price/name.
- Checkout validates form fields and creates a demo order in localStorage.
- Register/login demo runs in this browser.

IMPORTANT:
Frontend lab project only. No real payment gateway, delivery service, server or database.
Do not enter real payment details. Product images are stored locally and work offline.
Google Fonts are optional; fallback fonts are used if offline.

LAB 4 CONCEPTS:
CSS Grid for product cards/layouts; Flexbox for navigation, cart rows and card internals;
responsive breakpoints for mobile, tablet and desktop; responsive images and accessible labels.
